# Planejador de Negócio

App web de plano de negócio com abas Empresa, MVP, Produtos e custos, Comercial, Marketing, Operacional, Investimento, Financeiro e Viabilidade. Calcula custo e preço por markup, DRE e fluxo de caixa projetados, VPL, TIR, payback e ponto de equilíbrio.

Arquivo único (`index.html`), sem build. Os dados ficam salvos no navegador de quem usa; exporte/importe em `.json` para guardar ou mover.
